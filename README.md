# GPTase Detector

AI-generated text detection proof-of-concept using Hugging Face models.

## Quick Start

### Prerequisites

- Python 3.14+
- Node.js 18+
- npm or yarn

### Backend Setup

```bash
# Create virtual environment
python -m venv venv

# Activate it (Windows)
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Install backend dependencies
pip install -r backend/requirements.txt

# Start the API server
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

The API will be available at `http://127.0.0.1:8000`

Interactive API docs: `http://127.0.0.1:8000/docs`

### Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

The frontend will be available at `http://localhost:3000`

### Running Both

You'll need two terminal windows:

**Terminal 1 - Backend:**
```bash
venv\Scripts\activate
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

**Terminal 2 - Frontend:**
```bash
cd frontend
npm run dev
```

Open `http://localhost:3000` in your browser to use the detector.

## API Endpoints

### Health Check

```bash
GET /health
```

**Response:**
```json
{
  "status": "ok"
}
```

### Analyze Text

```bash
POST /api/analyze
```

**Request:**
```json
{
  "text": "Text to analyze for AI generation"
}
```

**Response:**
```json
{
  "prediction": "HUMAN",
  "human_probability": 0.9453,
  "ai_probability": 0.0527,
  "character_count": 119,
  "word_count": 22
}
```

**Example using curl:**
```bash
curl -X POST http://127.0.0.1:8000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "I grabbed coffee this morning at that new place downtown."}'
```

**Validation Rules:**
- `text` field is required
- Text cannot be empty or whitespace-only
- Maximum length: 10,000 characters

**Error Responses:**

Empty text (422):
```json
{
  "error": "Validation error",
  "detail": "body -> text: Value error, text cannot be empty or whitespace-only"
}
```

Text too long (422):
```json
{
  "detail": "Text exceeds maximum length of 10000 characters"
}
```

## How It Works

The detector uses the `rasbt/ai-text-detector-modernbert` model from Hugging Face, which is a ModernBERT-based classifier fine-tuned to distinguish between human-written and AI-generated text.

### Model Output

The model predicts one of two classes:
- **HUMAN** - Text likely written by a human
- **AI** - Text likely generated by an AI

The output includes probability scores for each class, showing the model's confidence in its prediction.

### Example Results

```
Example 1 (Conversational text):
-> Predicted: HUMAN
   HUMAN: 100.00%
   AI: 0.01%

Example 2 (Formal explanatory text):
-> Predicted: AI
   HUMAN: 0.14%
   AI: 100.00%

Example 3 (Short phrase):
-> Predicted: AI (lower confidence)
   HUMAN: 12.70%
   AI: 87.11%
```

## Important Disclaimer

**This tool provides probabilistic predictions, NOT definitive proof of authorship.**

- The model can and does make mistakes
- Short texts tend to have lower accuracy
- Writing style affects predictions (formal text may score higher as AI)
- Results should be used as guidance only, not as evidence
- Always use human judgment and additional context when evaluating text

## Technical Details

- **Model**: `rasbt/ai-text-detector-modernbert`
- **Architecture**: ModernBERT (BERT-based)
- **Task**: Binary sequence classification
- **Labels**: `HUMAN` (0), `AI` (1)
- **Backend**: FastAPI
- **Python**: 3.14.7
